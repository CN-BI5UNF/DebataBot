# 联网搜索（Web Search）

AI 需要实时信息时自动上网搜。默认走 Bing RSS，国内通常可直连、无广告，
不需要额外密钥。也可以在设置里换成百度或自建 SearXNG。

## 免费搜索

设置页 → 功能 →「联网搜索」→ 免费搜索：

| 后端 | 特点 | 备注 |
| --- | --- | --- |
| **Bing RSS**（默认） | 国内可直接连、RSS 无广告、速度快 | 受 Microsoft RSS 个人非商业使用条款约束 |
| **百度** | 国内可直接连、中文结果多 | 解析移动页，页面较大；频率过高可能触发安全验证 |
| **自建 SearXNG** | 免费、无广告、可长期稳定使用 | 需要自己的实例并开启 JSON 输出 |
| DuckDuckGo | 海外网络可用 | 国内大概率超时，已从设置选项移除，仅保留后端实现 |

选择 Baidu 或 SearXNG 后，先点「测速免费搜索」确认当前网络可用。SearXNG
还需要填写实例地址，例如 `https://searx.example.com`；公开实例不保证允许
JSON 或长期可用，长期使用建议自建。

免费搜索失败时，只有同时开启了官方搜索才会自动回退；只开免费搜索时不会
偷偷调用付费接口。

## 官方搜索（会消耗额度）

官方搜索调用模型/搜索厂商自己的联网搜索能力，可能按次或按 token 计费。
设置页会显示当前通道和费用提示；默认关闭，可随时开关。

| 提供商 | 搜索通道 | 计费/额度提示 |
| --- | --- | --- |
| DeepSeek | 独立 Search API | 官方公布 2026-11-01 起 ¥5 / 1000 次（以控制台为准） |
| 月之暗面 Kimi | 独立 Search API | 按官方 Search API 计费 |
| 智谱 GLM | 独立 Web Search API | 按官方搜索 API 计费，可选搜索档位 |
| 小米 MiMo | 聊天内置 `web_search` 工具 | 官方公布约 ¥16 / 1000 次（以控制台为准） |
| Google Gemini | Grounding with Google Search | 有免费额度，超出后按官方价格计费 |
| 通义千问 | `enable_search` | 按 DashScope 搜索计费 |
| OpenAI | Responses `web_search` | 按搜索调用/模型 token 计费 |
| Anthropic | Messages `web_search` 工具 | 按搜索次数计费 |
| OpenRouter | `web` 插件 | 按 OpenRouter 插件价格计费 |
| 火山方舟（豆包） | Responses `web_search` | 按火山方舟联网搜索计费 |
| xAI Grok | Responses `web_search` | 按 xAI 搜索计费 |

只给预设中确认有官方搜索能力的模型显示通道；没有官方搜索能力的模型不会
出现在官方搜索下拉框里。自定义 provider 不会自动猜测搜索接口。

## 回退顺序

- 免费 + 官方都开：先测速免费通道；免费不可用或本次请求失败，才回退官方。
- 只开免费：只用免费；失败时直接返回错误，不产生官方费用。
- 只开官方：直接使用官方，不探测免费。
- 两个都关：`web_search` 工具不可用。

## 更新页测速

设置 → 更新 →「测速 GitHub / 镜像」会依次对官方 GitHub 和预设镜像执行
`git ls-remote --tags`，显示每个目标的延迟/结果，方便选择可用镜像。
该操作只读，不会修改更新计划、配置或仓库内容。

## 注意

- 搜索是 AI 按需调用，不是每次回复都搜。
- 百度页面出现「安全验证」时会报错并提示换用 Bing RSS；本项目不绕过验证码。
- 商业部署请自行确认 Bing RSS / 百度 / SearXNG 及官方搜索接口的使用条款。
