# 开发快照 2026-10-23-2

更新页折叠与静态缓存的修复快照。功能与 `snapshot-20261023` 相同，可随时回退到上一个快照。

## 修复

- 更新日志的“展开/收起”不再只依赖 `app.css` 的 class：JS 同时设置内联
  `max-height/overflow`，即使浏览器缓存了旧样式，点击也能立即折叠。
- 静态前端资源改为每次重新验证（`Cache-Control: no-cache, must-revalidate`），
  入口 CSS/JS 增加版本查询串，避免升级后浏览器继续使用旧 WebUI。
- 设置 →「更新」的版本列表在网络请求期间不再阻塞整个页面。
- 总览绿标只提示可向前推进的 Release；分叉版本只在版本列表中手动选择。
- 本地 `refactor/main` 已指向目标、但工作树在另一条分支时，仍可切回目标版本。

## 使用提示

- 升级后如果浏览器仍显示旧样式，做一次强制刷新（Ctrl+F5 / Cmd+Shift+R）。
- 预设镜像包含 GitHub 官方、gh-proxy.com、ghfast.top、ghproxy.net，以及自定义
  https 输入。
- 回退只切换源码，不自动安装依赖、不回退数据库 schema。
