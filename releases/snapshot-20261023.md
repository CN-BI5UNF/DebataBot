# 开发快照 2026-10-23

首个通过 GitHub Releases/tag 管理的开发快照。当前仍为开发阶段，暂不发布正式版本号。

## 版本与更新

- 新增私有发布仓库 `CN-BI5UNF/DebataBot`，Releases/tag 作为版本目录。
- 设置 →「更新」可以查看每个版本的更新日志，展开/收起详情，更新、回退或切换到任意版本。
- 应用版本前会确认；旧 HEAD 备份到 `refs/backups/update/*`；用户数据目录不在更新范围内。
- 自动检查默认每 9 天一次，状态持久化；失败后 6 小时重试。
- 总览页发现新版本时显示绿色圆形上箭头；从该入口关闭后会询问是否“之后不再提示”。
- 新增常用 GitHub 镜像预设和自定义镜像；继续拒绝 http、账号密码、内网地址和指向其它仓库的地址。
- WebUI 右下角显示浅灰色“开发版”占位。
