## 联网搜索

### 免费搜索

- 默认使用 **Bing RSS**：国内可直连、结果无广告、无需密钥。
- 新增 **百度**：解析百度移动页，国内可直连，过滤明显广告和百度卡片；页面较大，
  请求频率过高可能触发百度安全验证，此时会明确报错并提示换用 Bing RSS。
- 保留 **自建 SearXNG**：填写实例地址并开启 JSON 输出即可；适合长期使用。
- DuckDuckGo 已从设置选项移除：当前网络实测超时，不再作为可选引擎；
  仅保留后端实现，避免旧代码引用报错。
- 三个免费引擎均做过实际联网测试：Bing RSS、百度，以及在本机启动的
  SearXNG（Bing upstream）实例。设置页仍提供「测速免费搜索」按钮。

### 官方搜索

- 新增可选的模型官方搜索通道，默认关闭；开启后会按厂商规则消耗
  API 额度或搜索次数，界面下方已写费用提示。
- 已适配预设中确认存在官方搜索 API 的通道：
  - provider 级独立搜索：DeepSeek Search、Kimi Search、GLM Web Search；
  - 模型级搜索：MiMo `web_search`、Gemini Google Search grounding、
    Qwen `enable_search`、OpenAI Responses `web_search`、
    Anthropic Messages `web_search`、OpenRouter `web` 插件、
    火山方舟 Responses `web_search`、xAI Responses `web_search`。
- 没有确认搜索接口的预设/自定义 provider 不会出现在下拉框，也不会被猜测调用。
- 回退顺序：免费 + 官方都开时，先测速免费通道；免费测速失败或本次请求失败
  才回退官方。只开一个时只用那个通道；两个都关时不注册 `web_search` 工具。
- 费用、额度和可用模型以厂商控制台为准；DeepSeek 公布的 2026-11-01 起
  ¥5 / 1000 次、MiMo 约 ¥16 / 1000 次已写入界面提示。

### 设置与更新页

- 设置 → 功能 →「联网搜索」改为专用卡片：免费搜索、官方搜索分开开关，
  支持选择引擎、SearXNG 地址、结果数、超时、官方通道和独立超时。
- 搜索设置一次校验、一次落盘；配置不合法时不会写入半套设置。
- 设置 → 更新新增「测速 GitHub / 镜像」：对官方 GitHub 和预设/自定义镜像
  执行只读 `git ls-remote --tags`，显示每个源的延迟、可用性和错误；
  可一键把可用源设为镜像。测速不会创建更新计划、不会写 `update_state.json`、
  不会下载或切换代码。

## NapCat 进程管理修复

- 修复 Windows「复制路径」带引号导致 `process_path` 无效的问题；配置加载和
  进程管理器都会去掉成对的中英文引号。
- 开启「由 Debata 拉起 NapCat」时，先对 OneBot 目标做一次短 TCP 探测；
  如果 NapCat 已由系统或手动启动并响应端口，跳过托管，不会重复拉起 QQ，
  退出时也不会杀掉外部 NapCat。
- 启动路径不存在时只记录警告并跳过托管，不再抛异常阻断 WS 连接。
- 设置页和向导文案已提示：NapCat 已在运行时请关闭托管，路径不要带引号。
