# 开发快照 2026-10-25

开发快照，不发布正式版本号。相对上一个快照，本次把备份/兼容/账本基础与
视觉设置 UI 一起发布；生产迁移、launcher 安装和服务重启仍需单独授权。

## 视觉设置

- 设置 → 功能改为两张独立卡片：
  - **主模型原生图片输入**：直接说明当前聊天模型是否被预设标记为支持
    `vision`，以及 `auto/on/off` 的行为；主模型能看图时不需要额外 provider。
  - **独立视觉识别（describe_image）**：关闭时隐藏详情；开启后使用已有
    provider 下拉，复用其地址与密钥。只有选择「自定义 OpenAI 兼容端点」或
    显式勾选「覆盖地址/密钥」时才显示 base_url 和 API Key。
- 新增 `PATCH /api/settings/vision`：一次校验、一次落盘，避免多次保存产生
  半配置或多份 config 备份；自定义端点的密钥写入 `vision_key`。
- 视觉配置更改后仍需重启 Runtime 生效。
