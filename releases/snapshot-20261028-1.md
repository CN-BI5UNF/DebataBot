# 开发快照 2026-10-28-1

> **已撤回**：本版本存在 `persona.active: debata` 旧配置导致升级后无法启动的问题，已在 [开发快照 2026-10-28-2](snapshot-20261028-2.md) 修复，并从 Releases 删除。

开发快照，不发布正式版本号。相对 `snapshot-20261025-3`，本次重点是知识/黑话按需引用、知识查重与共享、表情包工具和更新/重启可靠性。

## 知识 / 热梗 / 笔记

- 知识库改为按需查询：主模型通过 `list_knowledge_notes` 获取 active 笔记，不再每轮注入 `task_context`。
- 知识条目可逐条勾选“共享”：其他角色只读查询并参与查重，所属人格保留编辑/删除权。
- 保存前按标题/主题查重，覆盖同类型/跨类型同标题，以及“基本介绍 / 基本资料 / 简介 / 盘点”等泛化后缀；重复内容不写入。
- 联网考究会把现有标题和短摘要加入考究 prompt，并在落盘前再次查重；重复条目会计入“跳过重复”。
- 新增 `POST /api/knowledge/dedupe`：默认只预览，确认后合并保守重复并生成 `knowledge.json.dedupe-*` 备份。
- 知识页“刷新当前热梗”改为“获取当前热梗”。

## 群聊黑话

- 黑话页标题改为“群聊黑话”。
- 黑话改为知识库式按需引用：新增 `lookup_slang`，模型遇到不懂的缩写/群梗时查询当前群已确认词条；不再自动注入每轮上下文。
- 查询结果包含释义、用法、例句、风险和出现次数，不返回证据/来源。

## 表情包

- LLM 可调用 `list_emoji`、`save_emoji_from_url`、`save_emoji_from_workspace`、`rename_emoji`、`delete_emoji` 读取/修改表情包目录。
- 远程下载复用视觉链路的公网 IP 固定、重定向/大小限制和 magic 校验。

## 人格与文案

- 移除内置 `debata` 人格；新增内置 `deepseek` 完整群聊提示词。
- 侧栏、人格页、设置和向导统一把“角色”改为“人格”。
- 默认开箱人格仍为“大肥鱼”。

## 更新 / 重启 / 用量

- 更新时若依赖文件变化，默认自动执行 `pip install -e .`；无 pip 时回退 `uv pip install`，失败回滚源码。
- 修复 systemd 误判：按 cgroup 确认 `debata-agent.service`，VNC/桌面会话残留的 `INVOCATION_ID` 不再导致重启静默失败。
- 重启后端通过独立 helper 或 systemd 执行；WebUI 等待 `boot_id` 变化后才 reload。
- 官方搜索、视觉 `describe_image`、embedding、知识考究和黑话提取的 token 计入 V2 用量；“按用途”表可查看。
- 存储“安全清理”按钮改为“清除”（仍会先展示影响并确认）。
