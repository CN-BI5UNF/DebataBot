# KarenBot 开发快照 2026-10-28-3

本次快照完成项目从 **Debata_Agent** 到 **KarenBot** 的全量改名，并包含第二阶段 2.6 的上下文/存储优化基线。

## 改名

- 产品名：**KarenBot**
- 仓库：<https://github.com/CN-BI5UNF/KarenBot>（旧 `DebataBot` URL 由 GitHub 重定向）
- Python 发行包：`karenbot`
- CLI：`karen`；旧的 `debata` 命令保留为兼容入口
- 服务名：`karenbot`；旧的 `debata-agent` unit/运行目录继续识别
- 数据目录默认：`~/.local/share/KarenBot`（Windows：`%LOCALAPPDATA%\KarenBot`）
- 新环境变量：`KAREN_*`；旧的 `DEBATA_*` 仍识别
- 代码内部 `DebataDB`/`debata_stores` 等改为 `Karen*`；旧数据目录不会被删除
- WebUI、向导、设置、日志、文档和 README 全部更新为 KarenBot

## 兼容

- 旧 `debata` 命令、`DEBATA_DATA_ROOT`、`DEBATA_WEBUI_TOKEN`、`DEBATA_DISABLE_TREND_RESEARCH` 等继续工作；
- 检测到旧 `Debata_Agent` 数据目录时继续使用，并在日志中提示迁移；
- 旧 `persona.active: debata` 继续自动映射到 `deepseek`；
- 旧聊天分页 cursor 仍可解码；新 cursor 使用 KarenBot 密钥，并修复了签名中恰好包含 `.` 时的解析错误。
